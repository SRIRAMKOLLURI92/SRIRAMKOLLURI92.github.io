# Sriram Kolluri — Portfolio

Personal portfolio website built from scratch with HTML, CSS and JavaScript.

🔗 Live: https://sriramkolluri92.github.io

## Features
- Responsive design (mobile, tablet, desktop)
- Dark / light theme (saved in localStorage)
- Animated terminal and scroll reveal effects
- No frameworks, no build step

## Run locally
Open `index.html` in your browser.
